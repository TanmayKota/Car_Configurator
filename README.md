# Car_Configurator

This is an open source web based car configurator with 3 background areas:

1) Car Showroom
2) Sunset View
3) Underground garage

Currently there are 5 cars available but more cars can be added to it as per your requirements.

The cars can be rotated for better viewing angles.

They can be customized right from which paint would suit them to the type of seats and also the wood in the dashboard.

Currently 2 areas are ready that is car showroom and sunset view with the underground garage setup on its way.
